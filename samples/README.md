# Sample files

Real GoPro HERO10 Black files for trying ReefHue and for the optional real-media tests
(`tests/test_real_media.py`, which uses this folder by default).

| File | What |
|---|---|
| `GOPR2797.JPG` | Photo, 23 MP (5568 × 4176), EXIF and GoPro metadata |
| `GX012993.MP4` | Video, 3 s, 2.7K HEVC 8-bit full range, AAC audio, timecode and GPMF telemetry tracks |

The camera serial number was overwritten with `X` characters (same length, so no other byte
changed); the GPS track contains no position fix. They are provided under the repository's licence.
